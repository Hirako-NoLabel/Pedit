# v2.3.31

## 修改

- 扫描文字等长修改新增“稳定数字片段”策略：OCR 仍可整串识别，例如 `LH-K-100`，当用户修改为 `LH-K-600` 时，内部自动把修改范围扩展为 `100 -> 600`，而不是只把窄字符槽中的 `1` 单独替换成更宽的 `6`。
- 仅重建连续数字片段，前缀/后缀未修改文字仍保持原扫描像素，不恢复整字段重绘。
- 多个数字变化时同样合并到同一连续数字片段，例如 `ABC-100-X -> ABC-660-X` 只处理 `100 -> 660`。
- 非数字等长修改仍保持字符级局部替换。
- 扫描 patch 指标新增 `stableFragment`、`replacementFragments` 与 `replacement_char_indices`，用于区分“实际变化字符”和“为视觉稳定而参与重建的片段”。
- 保留 v2.3.30 的 1:1 原文复用能力；单字符数字片段仍可继续使用成品字 1:1 复用。
- 保存进度继续兼容读取 v2.3.30、v2.3.29、v2.3.28、v2.3.27 的本地进度。

## 未改动

- Native Scan Renderer、清晰度控制、输入字形保持、最终字形预览、4% 横向压缩保护。
- 页码数字槽、保存/基线、高清预览、bbox crop、修改记录双 Tab、Windows BAT 编码逻辑。
