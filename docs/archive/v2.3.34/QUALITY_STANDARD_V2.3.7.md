# QUALITY_STANDARD_V2.3.7

## 一、页面整体不被破坏

- 不改变原始页面整体布局；
- 不改变非目标区域文字、线条、印章、表格、签名、水印位置；
- 仅处理指定替换区域及必要的最小融合区域；
- 非目标像素变化必须为 0；
- 新字符不得覆盖未修改邻字或受保护长线。

## 二、替换结果与周围文本视觉协调

替换文本应尽量匹配同一行、同一字段附近扫描文字：

- 字高；
- 基线；
- 字符间距；
- 笔画完整性；
- 黑度/灰度；
- 边缘软化；
- 局部扫描质感；
- 与底图融合。

## 三、禁止明显编辑伪影

必须避免：

- 字体风格突兀；
- 发虚、发糊；
- 断笔、缺口；
- 白边、浅灰边、重影、毛边；
- 单字符明显偏浅/偏黑；
- 字符“贴上去”或“浮在纸面上”；
- 字距突变；
- 单字符与整串风格不一致。

## 四、程序级执行规则

- 字符 diff 优先；
- 最小修改区域优先；
- 行级局部 style profile；
- 非目标像素强制回写；
- tight patch；
- 邻字碰撞检查；
- 视觉质量门失败则阻止输出。

## 五、验收

- 70% / 100%：正常观察不应出现明显突兀字符；
- 200% / 300%：允许看见内容变化，但不应出现编辑伪影；
- before/after/diff：变化应集中在目标字符及必要的极小融合边界。
