# v2.3.26 变更记录

## 核心原则

v2.3.26 不改变 v2.3.25 已确认的页码“数字槽”逻辑：OCR 只定位原数字，目标当前页数字与总页数数字由用户配置；默认只替换数字，找不到原数字时不新增。

## 新增

- 修改清单：`渲染本页`、`渲染本页并跳到下一异常页`。
- 修改清单状态筛选：全部、已成功、异常、人工修改、已撤销。
- 导出选择：全选、取消全选、反选、只选异常页、只选当前页。
- 顶部 `保存进度`。
- 顶部 `保存并继续编辑`，生成连续 baseline 文件并自动继续编辑。
- 历史节点记录 baselineId，允许跨基线恢复。
- 保存进度后支持浏览器刷新与本地服务重启恢复 session。
- 预览质量：自动、标准、高清。
- 动态高 DPI 页面预览，后端页面/修改预览最高 8×。
- `/api/region-crop` 高清 PDF 坐标裁切。
- 成品字组保存改为 6× bbox crop，而不是从当前页面预览图二次截图。
- 局部编辑器改为 5×～8× 高清 crop。
- 图片替换显示源图尺寸、目标框尺寸和估算有效 DPI。
- 修改对象补齐 `objectId / batchId / role / bbox` 元数据。

## 行为调整

- 单页重新渲染只处理当前页，不提交或重绘其他页面。
- 单页渲染成功后可把当前异常页标记为已处理，随后跳到下一未解决异常页。
- “保存并继续编辑”写入新基线后，会清除本轮临时 edit / feasibility / 页码扫描结果 / 人工接管状态，并重新加载当前页。
- 导出界面中的勾选表示“本次写入 PDF 的修改”；普通修改清单中的勾选仍表示撤销选择。
- 撤销修改会保留一条“已撤销”清单记录。

## 清晰度修复

旧版本页面渲染倍率核心上限为 3×，前端主要按 1.7× 预览。v2.3.26 将显示比例与后端像素倍率解耦；自动模式按照显示宽度、zoom 和 devicePixelRatio 请求实际需要的像素，避免 2K/4K 或高倍缩放时浏览器放大低清 PNG。
