# v2.3.33

## 修复

- 修复 v2.3.32 稳定数字片段在未找到完整目标字组时，被“保持输入字形”4% 横向压缩保护误拦截的问题。
- `LH-K-100 -> LH-K-600` 仍按稳定片段 `100 -> 600` 处理；若同页同排找不到完整 `600`，现在进入独立的稳定片段宽度策略，而不是直接报错。
- 稳定片段回退采用等比例整体缩放来适配原数字块，保持字形纵横比；禁止只做横向压扁，也不重绘 `LH-K-` 等未修改区域。
- 当所需等比缩放过大（低于 78%）时仍会阻止生成并提示扩大数字片段范围，防止明显变形。
- 普通“保持输入字形”编辑继续保留原有 4% 横向保护，不受本次修改影响。
