# v2.3.19 Changelog

## 批量页码编辑重构

- 页码位置 A / B 改为 **直接在 PDF 页面拖框选择**，不再要求先点中 OCR / 文字对象。
- 新增 `/api/page-number-template/capture`：框内局部读取页码文字，并可合并被 OCR 拆开的多个页码 token。
- 框选后记录用户矩形作为页码模板位置，同时保存框内真实文字 bbox、字符坐标和数字分组。
- 模板卡片显示识别到的“当前页 / 总页数”等数字，便于批量前确认。

## 每页真实页码坐标优先

- 后续页面优先在投影后的框选区域内读取该页真实字符坐标。
- 不再把第一页页码 bbox 当作所有页面的最终输出坐标。
- 允许页脚在不同页面有小幅位置漂移，实际替换时使用目标页自身数字 bbox 和 baseline。

## 当前页 / 总页数原位拆分

- 对 `第92页，共92页`、`92/92`、`Page 92 of 92` 等结构，优先拆分数字子字段。
- 固定的“第 / 页 / 共 / / / Page / of”等文字不重绘。
- 同位数扫描页数字继续使用现有扫描字符修订流程。
- 电子 PDF 数字子字段使用页码专用局部替换，规避同页存在两个相同数字时高一致性定位歧义。
- 位数变化（例如 `9 → 10`）只替换对应数字子区域，不再重绘整段页码。
- 数字子字段使用真实原 bbox、真实 origin / baseline，并避免额外 1.5pt 内边距导致同位数字缩小。

## 空白页

- 对框选位置未识别到原页码的页面，继续按框选模板新增页码。

## 版本

- 更新至 v2.3.19。
