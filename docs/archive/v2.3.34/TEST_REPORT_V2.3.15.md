# TEST REPORT v2.3.15

## 本轮目标
新增“修改历史”功能，使用户在多次修改后可以直接选择任意历史节点返回，不需要连续点击撤销。

## 已实现
- 顶部“修改历史”入口。
- 自动记录：导入文档、文字修改、图片替换、批量修改、删除、页码重编号等历史节点。
- 历史条目显示时间、页码、操作摘要、节点编号、当前累计修改数。
- 支持任意节点直接“返回到此版本”。
- 返回历史节点时，当前状态先压入原有 Undo 栈，因此仍可继续撤销/重做。
- 返回旧节点后，原有后续历史不删除；新的恢复节点会保存 `sourceVersionId`，用于标识恢复来源。
- 支持“命名此节点”，可标记“型号完成版”“页码正确版”等关键状态。
- 恢复历史后自动跳转到该节点对应页。

## 设计边界
- 当前历史记录属于本次打开 PDF 的编辑会话；重新导入文档会创建新的历史链。
- 历史节点保存的是编辑状态快照，不复制整份 PDF 文件，因此返回速度较快。
- 当前最多保留 160 个可视历史节点；Undo 栈继续保持原项目的 80 步限制。
