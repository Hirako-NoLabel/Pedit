核心例 `LH-K-100→LH-K-500` 始终定位变化索引 5。像素证据显示变化局限于字符附近，未修改整行。`LH-K-` 与 `00` 的原图对象保留；真实 PDF 重采样允许极小边缘差异，不能把“对象保留”说成所有缩放下区域内像素严格相同。

正常 70%/100% 下文字可读，未见整段重绘、明显矩形白块。200%/300% 下仍有轮廓、局部宽度、笔画软化/灰度差异；因此 BUG-02 总体验收不写“已完全解决”。

水印：修改区域之外保持不变；原文字遮住部分采用 inpaint，未声称从不可见像素恢复精确原纹理。`expectedCropMAE` 衡量独立期望图与结果的局部误差；`backgroundRestorationMAE` 还会受到新字位置/字形差异影响，只是诊断信号，不能当作纯背景质量分。

评分中的 `color_score`、`background_score` 保留为 null，避免对无法可靠分离的色彩/遮挡背景编造分数。字体、水平/垂直比例、笔画、RGB、软化、噪声残差、像素采样步长均记录；扫描倾角明确标为未估计。噪声残差可能混入结构，非扫描仪标定结果。

## 回归、维护成本与边界

本轮测试范围内未发现未修复的功能回归。不是对全部未知 PDF 的保证。新增可靠性检查会拒绝估算坐标、大幅增长或互相覆盖的字符编辑，属于有意收紧；它可能降低某些低质量 OCR 材料的可改范围。

电子核心未动；扫描拟合独立在 `scan_diff.py` / `scan_visual_match.py`，原渲染模块继续承担局部合成，避免从零重写。测试集增加运行成本，字体拟合也比固定字体开销更高。测试使用 Windows 字体；跨平台测试生成器尚未适配。整体缓存策略沿用原项目，未进行大型多文档压力测试。

尚未实现完整倾角、独立 tracking 优化或不可见水印重建。长度变化只处理必要尾部，极端增长拒绝；不默认退到整行大范围擦除。重叠修改需先恢复，再编辑整行。fit 模式 resize 复位到顶部，不保留阅读锚点。
