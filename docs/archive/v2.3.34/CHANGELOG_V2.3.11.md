# CHANGELOG v2.3.11

基于 v2.3.10 增量修改。

## 1. 默认视图
- 导入 PDF 后默认由 `fit-page` 改为 `fit-width`。
- 首次加载自动适应宽度、复位滚动并居中。
- 翻页和 ResizeObserver 继续保持当前 viewMode。

## 2. 视觉微调自由度
- 背景边缘融合：0~100 改为 -100~+100，0 为自动中性点。
- 后端同步支持负向融合：负值收紧清理边界，正值扩大柔和过渡。
- 大小/宽度：50%~150%。
- X/Y：±20px。
- 深浅：±100。
- 笔画：±6。
- 扫描柔化：±4。
- 页面保护、邻字碰撞与硬安全门保持启用。

## 3. 应用微调进度
- 点击“应用微调并重新预览”后，页面显示旋转状态、百分比与进度条。
- 进度与原 5 阶段定位/OCR/生成/渲染/验证流程同步。
- 运行期间禁止重复点击。

## 4. 原页码批量重编号
- 工具栏新增“页码重编号”。
- 用户指定实际 PDF 页范围 + 新起始页码，结束页码自动计算。
- 程序逐页扫描现有页码，只替换检测到的原数字，不新增额外页码。
- 支持纯数字、第 N 页、Page N、N / Total。
- 未识别页面明确显示“跳过”，保持原样。
- 页码替换复用现有电子/扫描双引擎和批量可行性检查。
