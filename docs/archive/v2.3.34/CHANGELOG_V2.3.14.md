# v2.3.14 Changelog

## Added

- 新增“成品字复用”区域：复制成品字、粘贴成品字。
- 新增“原样粘贴 / 适配目标字符槽”两种复用模式。
- 新增当前 PDF 临时成品字库，同一字符保存最近一次满意成品。
- 扫描修订引擎可输出背景透明的最终字符 alpha 资产，并在目标位置重新执行页面保护与背景融合。

## Safety / consistency

- 成品字资产不包含源位置背景、水印、横线或表格像素。
- 粘贴后仍执行最小修改区域、旧字清理、页面保护和邻字重叠检查。
- 仅支持可靠的单字符替换生成成品字；多字符变更不会误当成单字资产。
- 成品字库仅在当前 PDF 会话内有效，导入新 PDF 自动清空。
