# v2.3.25 变更记录

## 页码工作流重构：数字槽

1. 将页码批量操作改为“当前页数字槽 + 总页数数字槽”。
2. 框选完整页码后新增角色选择：自动识别 / 只改“第几页” / 只改“共几页” / 当前页 + 总页数。
3. 当前页数字按用户配置的起始数字和步长逐页计算，不再依赖原 OCR 数字的连续关系。
4. 总页数改为固定用户输入值，不再通过模板或 OCR 原值推导。
5. 同一个完整页码框可以同时提取两个数字，只替换选定数字子区域；固定文字、标点和分隔符不重绘。
6. 扫描结果改为直接显示“识别到什么数字 / 将原位替换成什么数字”。
7. 默认不新增页码；找不到原数字时进入重新定位或人工接管。
8. 保留多位置、页段范围、试运行、异常筛选、人工接管、删除批量内容和历史撤销。

## 兼容

- 保留原页码扫描 API 与已有编辑对象格式。
- 保留 v2.3.21-v2.3.24 的手动框选、可移动字块、修改清单撤销及初始居中修复。
