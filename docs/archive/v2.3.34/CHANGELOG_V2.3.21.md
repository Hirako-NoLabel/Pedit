# v2.3.21 Changelog

- 全局新增任意手动框选编辑，不再局限于页码；框选区域可重新识别、改字、删除或转为自由新增文字。
- 新增统一可移动文字块交互：拖动、八向缩放、X/Y/W/H 0.1 精调、方向键微调、锁定、吸附、局部放大编辑。
- 新增成品字组 / 短语复用和当前页对象层面板。
- 普通批量和页码批量新增首/中/末 3 页试运行。
- 页码位置由 A/B 扩展为任意多个动态框选位置（最多 12 个）。
- 每个页码位置支持独立适用页范围，允许不同页段使用不同页码位置模板。
- 新增单页“此页重定位”，用于处理 91 页后等版式突然变换的情况。
- 新增页码连续性逻辑校验，OCR 结果与模板连续关系不一致时停止自动写入。
- 未识别到原页码时默认禁止自动新增；只有显式开启“允许新增”后才会生成。
- 批量生成页码可直接点击选中，并支持修改、移动、缩放、删除当前字块。
- 新增“删除此页此组”和“撤销上次页码批量”，解决错误批量结果无法清理的问题。
- 修复批量页码字块再次手工修改时，预览候选中可能同时包含旧对象和新对象的问题。
- 版本更新至 v2.3.21。
