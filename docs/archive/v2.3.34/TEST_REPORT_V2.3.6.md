## Windows 侧建议验收

使用相同 PDF 连续测试至少三个位置：

- `LH-K-100 → LH-K-600`
- 另一行 `LH-K-100 → LH-K-600`
- 第三个相近字号字段 `LH-K-100 → LH-K-600`

检查：

- 三处 `6` 的字宽是否趋于一致；
- 三处黑度/边缘软化是否不再随 donor 改变；
- 不应因页面其他行存在 `6` 而突然切换到另一种字形/曝光；
- 100% 下不同位置的修改结果应保持同类视觉风格。

## 已知限制

- 若目标行只有一个 `1`，没有任何其他可靠数字，仍需退回字段上下文字体拟合。
- 严格同行策略会减少 same-page exemplar 使用率，这是有意设计，用稳定一致性换取避免跨行风格污染。
