# CHANGELOG v2.3.28

## 修复

- 顶部查看工具栏的“适应整页 / 适应宽度 / 净预览”改为“整页 / 页宽 / 净图”，完整说明放入 title，避免窄宽度或浏览器缩放时文字超出按钮。
- 扫描文字新增并默认使用“保持输入字形（所见即所得）”。Windows 优先 Segoe UI，缺失时回退 Arial / Liberation Sans / DejaVu Sans。
- 保持输入字形模式不再允许后台进行明显横向压缩；超过 4% 压缩需求时阻止生成并提示用户扩大字段或手动调整。
- “修改为”输入框下新增最终字形预览，随文本和字形策略即时更新。
- 自动匹配模式继续保留，用户可显式切换回同行同字/扫描风格匹配。

## 兼容

- 版本升级为 2.3.28。
- 进度保存键升级到 v2.3.28，并兼容读取 v2.3.27 的本地保存记录。
