# CHANGELOG v2.3.23

## 修复

1. **页码批量识别过度阻断**
   - v2.3.20 起为了防止固定中文重复，格式化页码在缺少字符级数字坐标时会直接阻止整段替换。
   - 某些扫描 PDF 的 OCR 只能给出整块 bbox，导致 v2.3.22 出现“几乎每页都识别到文字但全部无法修改”的回归。
   - v2.3.23 对用户手动框选且结构一致的页码启用安全整段替换兜底：先清理真实旧字段，再按同一字段位置写入目标页码。

2. **单数字页码角色误判**
   - `第95页` 这类单数字框继续识别为 `{current}`。
   - `共96页`、`页共96页`、`Total 96`、`Page ... of 96` 的单数字框优先识别为 `{total}`。

3. **两数字模板被单个附近数字抢占**
   - 框选模板包含两个数字角色时，扫描不再因为先看到一个附近数字就提前认定命中。
   - 会继续寻找满足数字组数量要求的页码候选。

4. **PDF 导入后页面偶发不居中**
   - 画布容器从 flex/max-content 调整为 grid/fit-content。
   - 导入页面图像后等待两帧布局稳定，再执行 fit-width 和二次居中。
   - 居中滚动位置直接基于当前 pageWrap 的实际位置和宽度计算。

## 保持不变

- v2.3.22 的修改清单逐项撤销、回到修改前、多选撤销。
- 页码异常页手动接管、删除本页生成内容、单页重定位。
- 任意框选、可移动文字块、自由新增文字、成品字组、对象层、历史版本。
