# v2.3.22 变更记录

## 1. 修改清单真正可逆

- “本次修改清单”每一项新增：**定位 / 撤销此项 / 回到此项前**。
- 支持复选框多选后执行 **撤销选中修改**。
- 撤销不是只删除清单文字，而是从当前编辑状态移除对应编辑对象，因此页面会恢复原 PDF 内容。
- “回到此项前”会恢复整份文档到该修改首次出现之前的历史节点；该项之后的其他修改也会一并回退。
- 每条清单显示它首次出现的历史节点编号与时间，方便判断回退范围。

## 2. 所有批量页码对象都可人工删除/编辑

- 修复一个关键遗漏：批量页码中，部分同长度扫描数字以前以普通 `text` 类型保存，虽然页面已经改了，但前端没有把它当作“生成的页码对象”显示，因此难以直接删除。
- 现在只要编辑对象带有 `pageNumberSlot`，无论底层类型是 `text`、`page-number-add` 还是 `page-number-replace`，都会作为页码生成对象显示。
- 这些对象现在都可以：
  - 单击选中
  - 手工修改文字（包括总页数）
  - 鼠标拖动
  - 调整大小
  - X/Y/W/H 精调
  - 恢复原区域
  - 单独删除
  - 删除整组

## 3. 异常页码“人工接管”

- 页码扫描结果新增 **手动接管**。
- 支持按单个位置接管，也支持 **手动接管本页**。
- 被人工接管的页/位置，后续“试运行”和“逐页生成”都会自动跳过，不会再次覆盖人工修正。
- 如果该页已经有自动生成对象，接管后会直接定位到这些对象，可修改/移动/删除。
- 如果该页尚未生成对象，则自动切换到“任意框选”，可以直接手动框选需要修正的页码。
- 支持 **恢复自动**。

## 4. 页面级清理

- 页码结果行增加 **删除生成内容**。
- 每一页增加 **删除本页生成内容**，一次清掉该页所有批量页码对象并恢复原区域。
- 保留已有“删除此页此组”和“撤销上次页码批量”的底层能力。

## 5. Windows 启动体验

- `start_windows.bat` 版本提示更新到 v2.3.22。
- 新增 `启动编辑器.bat`，Windows 用户可直接双击启动。
- 正式 ZIP 改为打包项目根目录内容，Windows “全部解压”后不会再额外出现一层同名目录。
