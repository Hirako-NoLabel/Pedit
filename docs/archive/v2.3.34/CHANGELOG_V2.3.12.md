# CHANGELOG v2.3.12

## Added

- 视觉微调每个参数独立复位。
- 视觉微调“复制参数 / 粘贴参数”，一次复制整套 visualAdjust。
- 文字对象“删除此文字”。
- 图片对象“删除此图片”。
- 删除确认/批量预览弹窗。
- 相同文字全文匹配删除。
- 相同/高度相似图片匹配：优先 digest，相似图片使用 pHash。
- 删除匹配结果复选清单与页范围筛选。
- 局部删除 raster inpaint patch。
- 删除操作加入修订清单并可使用原有撤销/恢复机制。

## Changed

- 版本号更新为 v2.3.12。
- 当前参数复制不包含文本内容和对象位置，仅包含视觉微调参数。
- 删除操作不经过普通“新文字不能为空”的文字修改校验，而是走独立删除路径。
- 预览时跳过删除 edit 的普通文字 feasibility，避免与空字符串修改逻辑冲突。

## Preserved

- v2.3.11 的默认 fit-width。
- 页码重编号。
- 微调运行进度。
- 扫描文字质量门、页面保护与邻字碰撞检查。
- Demo 修订标记默认关闭。
