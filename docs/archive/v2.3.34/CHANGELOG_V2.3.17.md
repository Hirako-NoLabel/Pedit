# v2.3.17 Changelog

## 批量页码编辑重做

- 顶部“页码重编号”更名为“批量页码编辑”。
- 用户先在任意页面选中页码字段，再设为位置 A / B；每页最多两个模板位置。
- 页码模板支持：当前页、总页数、当前页/总页数、中文格式、自定义格式。
- 模板变量：`{current}`、`{total}`、`{pdfpage}`。
- 总页数来源支持：按编号范围、PDF 总页数、手动输入。
- 目标页存在原页码时按模板位置匹配，不再要求各页旧页码文本相同。
- “当前页 + 总页数”字段优先拆分数字部分修改，固定前缀/分隔符/后缀尽量保留原像素。
- 目标位置为空时新增页码；扫描页使用透明的扫描风格栅格字形，电子页沿用字体插入逻辑。
- 批量执行采用逐页检查、逐页渲染、逐页提交；单页/单位置失败会记录并继续后续页面。
- 页码操作纳入修改历史与修改清单。

## 兼容

- 保留旧 `/api/page-numbers/scan` 接口供旧版本兼容，但新界面改用 `/api/page-number-template/scan`。
