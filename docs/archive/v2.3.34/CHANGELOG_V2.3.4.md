# CHANGELOG_V2.3.4

## 范围

基于 v2.3.3 增量修复四项问题；v2.3.3 原始 ZIP 保留。仅使用虚构/合成 PDF 测试。

## 修改

- OCR 完整行与 subfields 分离，补齐中文前后段；按实际点击位置选择，增加编辑整行。重复字段按原文偏移匹配。
- 标注 RapidOCR 均分估算坐标，阻止将其当作安全擦除坐标。ASCII 字段在可验证时按墨迹分组校准，避免字符框切穿旧字。
- 等长文本按变化字符生成独立补丁；长度变化只处理必要尾部。拒绝重叠字符修改。
- 用原字符拟合字体候选、横纵比例、笔画、颜色及软化；窄数字用同一行其他数字的拟合参数参考。参考像素不复制、不移动、不删除。
- 背景仅修补墨迹；长线保护要求长度明显大于字高，防止把数字 1 保留成表格线。补丁按原扫描采样网格降采样。
- 避免二值 PDF 透明遮罩与 RGB 独立重采样造成亮边。实际补丁是带原局部背景的字符区域 RGB 图。
- Viewer 新增 fit-page/fit-width/custom，首次适应整页、顶部定位、居中、翻页保留模式、ResizeObserver 防抖重算；统一屏幕与 PDF 坐标换算。
- 默认从 PDF 应用层禁用修订标记、电子/图片高亮和修订附页；环境变量 Demo Mode 可主动恢复。
- 修复撤销/重做后校验缓存清空导致预览退回原图：恢复修改会重新校验，异步预览防止旧请求覆盖；净预览与实际导出逐像素一致。
- 保留电子文字引擎、图片、原水印、批量、净预览、撤销/重做、导出及修改清单能力。修正旧版页面/启动脚本/API 版本号不一致。

## 验证与状态

39 项 pytest 通过；实际浏览器交互和导出回归通过。8 组五倍率视觉材料、300% 对比及像素统计随项目提供。

BUG-01、03、04 在已测试环境解决。BUG-02 的字符局部处理已完成，视觉融合仍有字体、宽度、灰度及软化差异，最高目标未完全达标；详见测试报告，不以“优化”代替具体结论。
