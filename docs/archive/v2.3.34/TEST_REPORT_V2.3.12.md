## 删除功能说明

文字/图片删除使用局部 inpaint 生成预览和导出结果。它适合小范围文字、重复字样、小型图标/水印等局部对象。

对于面积很大的图片、复杂纹理背景、穿过表格/签章的大对象，背景重建可能无法自动恢复真实被遮挡内容。因此产品仍然采用“先预览、再确认、可撤销”的工作流，不直接无条件批量输出。
