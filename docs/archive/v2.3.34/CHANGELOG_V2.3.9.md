# CHANGELOG v2.3.9

基于 v2.3.8 增量修改。本轮不改变 OCR、字符 diff、Viewer、Demo Mode 和电子 PDF 高保真路径，新增“自动视觉匹配 + 非破坏式人工微调”。

## 新增：扫描文字视觉微调

扫描文字选中后新增独立的“视觉微调”区域：

- 字形候选：自动、Times、Arial、Calibri、Cambria、宋体、微软雅黑；系统没有对应字体时自动回退。
- 大小：80%–120%。
- 宽度：75%–125%。
- 左右微移：±6 渲染像素。
- 上下微移：±6 渲染像素。
- 深浅：-45–+45；正值更深。
- 笔画：-2–+2；用于修正过细/过粗。
- 扫描柔化：0–2.5 px。
- 旧字清理：0–100；50 保持 v2.3.8 默认行为。
- 背景边缘融合：0–100；默认 0，保持 v2.3.8 默认行为。
- “恢复自动”：一键回到自动匹配参数。
- “应用微调并重新预览”：仍经过页面保护和邻字碰撞硬门。

## 非破坏式约束

- 手动参数只作用于当前扫描替换字符及其旧字清理区域。
- 非目标像素仍由 `preservationViolationPixels == 0` 规则强制保护。
- 表格长线、原始水印、邻字保护逻辑保持不变。
- 大小/宽度/位置调整会扩大“采样 crop”，但不会扩大旧字擦除区域。
- 新字碰撞未修改邻字时仍阻止输出。
- 导出与预览使用同一 `visualAdjust` 参数，避免预览和最终 PDF 不一致。

## 清理强度

`cleanupStrength=50` 与 v2.3.8 默认清理路径兼容：

- 低于 35：保守清理，降低误伤复杂背景的概率，但可能保留更多旧墨迹。
- 50：自动默认。
- 高于 58：扩大旧字墨迹 mask；高强度时增加一档局部 mask 膨胀。
- 清理 mask 始终受当前 OCR 字符单元保护，不允许扩散到整行。

## 背景边缘融合

背景融合只发生在旧字清理边界，不对整页或整行做模糊。页面保护门最终会恢复任何不允许变化的非目标像素。

## 兼容性

- 默认参数下，扫描 patch 与 v2.3.8 保持相同输出；Linux 合成样本已做 SHA-256 逐字节兼容验证。
- 电子 PDF 路径不读取 `visualAdjust`。
- 批量应用扫描字段时会继承当前字段的视觉微调参数。
