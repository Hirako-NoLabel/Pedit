# v2.3.30

## 原文 / 成品字 1:1 保真复用

- 将“原样粘贴”升级为“1:1 原文复用”，作为成品字复用的默认模式。
- 成品字资产升级到 assetVersion 2：除兼容用 alpha mask 外，新增背景透明 RGBA 字形精灵，保留最终边缘、灰度纹理与像素级字形外观。
- 保存源字相对字符槽的 X/Y 锚点、字符槽尺寸、渲染倍率和锐度信息。
- 1:1 模式粘贴时只做坐标平移，不重新选字体、不重新渲染、不执行尺寸适配、不二次锐化/柔化，也不进行 ±2 px 自动横向寻位。
- 目标字符槽比源字窄时，1:1 模式直接阻止隐式缩放并给出提示；只有用户主动选择“允许缩放适配”才允许重采样。
- 源字与目标渲染倍率不一致时，1:1 模式直接提示重新复制或改用适配模式，避免隐式重采样。
- 自动成品字复用默认从旧版 `fit` 改为 `original`，避免后台自动缩放导致清晰度和字形比例变化。

## 兼容性

- 保留旧 assetVersion 1 的 alpha 成品字兼容读取。
- “允许缩放适配”继续保留旧版 fit 行为，供目标字符槽尺寸确实不同的场景手动使用。
- Native Scan Renderer、页码数字槽、保存/基线、高清预览、修改记录等既有功能未改动。
