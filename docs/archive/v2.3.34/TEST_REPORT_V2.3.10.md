# v2.3.10 测试报告

## 本轮目标
- 扩大视觉微调可调范围。
- 允许“扫描柔化”向负方向调整，以提高字符边缘清晰度。
- 将“应用微调并重新预览”“批量应用到其他页面”改为与“开始运行”一致的黑色主操作按钮。

## 参数范围
- 大小：60%–140%
- 宽度：60%–140%
- 左右：-12px–+12px
- 上下：-12px–+12px
- 深浅：-80–+80
- 笔画：-4–+4
- 扫描柔化：-2.5–+2.5（负值=提高清晰度，正值=柔化）
- 旧字清理：0–100
- 背景边缘融合：0–100

## 实现说明
负向扫描柔化仅作用于新 glyph alpha mask，使用受限 UnsharpMask，不作用于整页；页面保护、邻字碰撞和质量门仍继续执行。

## 验证
- Python 编译检查：通过。
- JavaScript 语法检查（node --check）：通过。
- v2.3.9 手动微调 + v2.3.10 新专项测试：8 passed。
- v2.3.7/v2.3.8 质量门 + v2.3.9/v2.3.10 相关回归：17 passed。

## 兼容性
默认值保持不变，因此不主动改变 v2.3.9 的自动视觉匹配结果；只有用户拖动滑块后才使用扩展范围。
