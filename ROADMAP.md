# Roadmap

## Before the first public tag

- Confirm source ownership and provide complete corresponding source for the AGPL distribution.
- Enable private security reporting and publish a conduct contact.
- Run the hosted CI matrix and manually accept the UI on target platforms.
- Verify the optional OCR/model dependency chain and model download behavior.

## After 0.1.0

- Extend portable regressions for CJK, rotated/encrypted PDFs, mixed scan/text pages and batch page numbering.
- Add broader browser automation for undo/redo, selection, preview and export.
- Define a portable, versioned project archive and migration policy before claiming cross-machine project portability.
- Review local HTTP access controls, resource limits and hostile PDF isolation.
- Add lockfile/dependency updates and deeper linting in focused changes.
- Consider translated UI and signed desktop builds after licensing and packaging are settled.

No delivery dates or compatibility guarantees are implied.
